# 🎭NPC 캐스팅룸

SillyTavern 채팅에서 잠깐 등장한 NPC를 발견해 임시 후보로 올려두고, 원하는 NPC를 골라 캐릭터 카드 양식의 로어북 항목으로 데뷔시키는 확장입니다.

## v1.6.2 캐릭터 시트 바깥 태그 제거

- 캐릭터 시트 따라하기에서 견본의 `<{{char}}>`·`</{{char}}>`는 메인 캐릭터를 가리키므로 NPC 항목에 복사하지 않습니다. 내부 섹션의 항목 이름·순서·마크업은 그대로 따릅니다.
- AI가 바깥 태그를 출력해도 초안 표시와 로어북 저장 전에 제거합니다. 이미 저장된 항목은 자동으로 수정하지 않으며, 해당 NPC를 갱신하면 새 내용에서 제거됩니다.
- 「기본 NPC 시트」는 가장 짧은 5줄 요약(약 100–180 영어 토큰), 「중간 NPC 시트」는 SOLO BOT 시트에서 9개 주요 섹션을 추린 중간 길이(약 300–500 영어 토큰)로 정리합니다. 이 길이는 AI에게 제시하는 목표이며 하드 컷은 아닙니다.
- 이전 「기존 기본 양식」 선택값은 새로운 짧은 기본형으로 전환합니다. 카드 설명이 없는 캐릭터 시트 따라하기는 기존의 공통 양식으로 계속 폴백합니다.

## v1.6.1 시트 구분과 화면 수정

- 중간 NPC 시트를 9개 섹션의 상세 프로필로 바꿨습니다. 신상·역할, 외형·인상, 성격·동기, 행동 방식, 말투, 관계, 배경, 현재 상황·목표, 연속성 정보를 다뤄 최소형의 5줄 요약과 구별합니다. 근거가 없는 섹션은 생략합니다.
- 스타일을 실행 시에도 직접 불러와 PC에서 버튼 글자가 한 글자 폭으로 접히는 문제를 방지했습니다. 버튼과 목록의 너비·줄바꿈을 보강했습니다.
- 마법봉 메뉴의 「NPC 캐스팅룸」에서 후보·설정을 같은 팝업으로 열 수 있습니다. 확장탭과 상태를 공유합니다.
- 모바일 탭에서는 현재 선택된 「캐스팅 후보」 또는 「설정」 버튼에만 테두리를 표시합니다.

## v1.6.0 NPC 시트 양식 추가

- 「중간 NPC 시트」는 외형·행동·말투·관계·사건을 적당한 길이로 정리하고, 「최소 NPC 시트」는 다시 등장할 때 필요한 특징만 짧게 정리합니다. 두 양식 모두 갱신 시 기존 내용을 무작정 덧붙이지 않고 새 장면과 합쳐 다시 작성합니다.
- 「직접 설정한 양식」에서 항목 순서·길이·표기법을 프롬프트로 지정할 수 있습니다. 입력 내용은 자동 저장되며 생성·갱신 양쪽에 적용됩니다. 출력 언어와 추론 설정은 기존 설정을 따릅니다.
- 기존 「캐릭터 시트 양식 따라하기」와 「기존 기본 양식」도 유지합니다. 기존 설정과 로어북 항목은 그대로 사용할 수 있습니다.
- 저장 시에는 이전과 같이 연결된 캐릭터/채팅 로어북에 항목을 추가하고, 연결이 없으면 새 로어북을 만들어 연결합니다. 초안 확인 후 저장 버튼을 눌러 실제로 기록합니다.

## v1.5.2 소유격 이름 처리

- "Dana's", "Kieran's"처럼 소유격이 붙은 이름을 원형으로 정규화한 뒤 제외 판정을 합니다. 페르소나·캐릭터 이름의 소유격이 NPC 후보로 잘못 올라오지 않습니다.
- NPC 이름의 소유격("Marcus's")은 원형("Marcus")과 같은 후보로 합산됩니다.

## v1.5.1 스캔 범위 자유 입력

- 스캔 범위를 선택지 대신 5 이상 원하는 개수로 직접 입력할 수 있습니다.

## v1.5.0 모든 상한 해제

- 사실상 모든 내용 제한을 없앴습니다. 남은 것은 백만 자급 폭주 방지 백스톱뿐이며, 실제 콘텐츠가 도달할 수 없는 값입니다.
- 등장 장면 전달: 8개·1,500자 → 스캔 범위 내 전부·메시지 전문
- 필드 길이(외모·성격·말투·관계 각 1만 자), 사실 50개, 예시 대사 30개, 별칭 20개, 로어북 키워드 30개로 확대
- "사실 5개·대사 4개까지" 같은 개수 지시를 제거하고 "장면이 뒷받침하는 만큼 전부"로 변경
- 스캔 범위에 최근 답변 100개·200개 선택지 추가

## v1.4.3 긴 캐릭터 시트 대응

- 응답 토큰 상한(30000)을 없앴습니다. 256 이상 원하는 값을 자유롭게 입력할 수 있습니다.
- 견본 시트 전달(3,500자 → 60,000자), 생성된 시트 저장(5,000자 → 120,000자), 갱신 시 기존 내용 전달(1,500자 → 30,000자) 제한을 대폭 완화해 긴 캐릭터 시트도 잘리지 않습니다.
- "시트를 간결하게" 지시를 제거하고, 견본 양식이 요구하는 만큼 길고 상세하게 작성하도록 바꿨습니다.

## v1.4.2 출력 언어 설정

- 로어북 항목 내용을 항상 지정한 언어(기본 영어)로 작성합니다. 시트의 항목 라벨·마크업은 견본 그대로 유지합니다.
- "(추정)" 표시는 언어 설정과 무관하게 항상 같은 표기를 사용하므로, 표시 지우기 버튼이 계속 동작합니다.
- 예시 대사는 언어 설정과 무관하게 채팅 원문 그대로 발췌합니다.

## v1.4.1 (추정) 표시 지우기

- 「(추정) 표시 지우기」는 추론된 내용은 전부 그대로 두고, "(추정)"이라는 표기만 한 번에 제거합니다.

## v1.4.0 초안 미리보기

- 생성 결과를 바로 저장하지 않고, 패널에 전체 초안을 먼저 보여줍니다.
- 초안 아래 「💾 로어북 저장」·「🧹 (추정) 표시 지우기」·「✖ 생성 취소」 버튼으로 확인 후 결정할 수 있습니다.
- 취소하면 로어북에 아무것도 저장되지 않습니다. 채팅을 전환하면 초안은 사라집니다.

## v1.3.1 빈 항목 추론 채우기

- 기본값으로, 장면에 직접 나오지 않은 시트 항목도 NPC의 행동·말투·맥락에서 그럴듯하게 추론해 채웁니다. 추론한 값에는 "(추정)"이 붙어 관찰된 사실과 구분됩니다.
- 추론은 장면에 나온 내용과 모순될 수 없다는 제약을 함께 지시합니다.
- 설정에서 끄면 이전처럼 확인된 정보만 기록하고 나머지 항목은 생략합니다.

## v1.3.0 카드 시트 양식 따라가기

- 기본값으로, 현재 캐릭터 카드의 설명(시트)을 양식 견본으로 삼아 같은 섹션 구성·항목 이름·마크업 스타일로 NPC 항목을 작성합니다. 견본 카드의 내용은 복사하지 않고 형식만 따라합니다.
- 카드 설명이 비어 있거나 그룹챗이면 캐스팅룸 기본 양식으로 저장합니다. 설정에서 기본 양식으로 고정할 수도 있습니다.
- 응답 토큰을 선택지 대신 256~30000 사이 원하는 값으로 직접 입력할 수 있습니다.

## v1.2.2 잘린 응답 복구

- 응답 토큰 한도에서 중간에 잘린 JSON을 복구해서 살릴 수 있는 만큼 프로필로 사용합니다.
- AI 지시에 마크다운 금지와 필드 길이 제한을 명시해 응답이 잘릴 가능성을 줄였습니다.

## v1.2.1 추론 모델 대응

- 추론(thinking) 모델이 보내는 `<think>` 블록을 응답에서 제거한 뒤 JSON을 찾습니다.
- 응답이 비어 있으면 토큰 부족 가능성을 안내하고, 설정의 「응답 토큰」(기본 1200)을 최대 4000까지 올릴 수 있습니다.
- JSON을 찾지 못한 경우 응답 시작 부분을 에러에 표시해 원인 파악이 쉬워졌습니다.

## v1.2.0 후보 합치기

- 같은 NPC가 성·이름·별명으로 따로 감지된 경우, 후보를 체크해서 하나로 합칠 수 있습니다. 대표 이름은 직접 정할 수 있어요(예: "캘런"+"밴스" → "캘런 밴스").
- 합친 이름 전부가 로어북 키워드로 저장되어 어느 이름으로 불려도 항목이 발동됩니다.
- 프로필 생성 시 등장 장면 수집과 AI 지시에도 모든 이름이 같은 인물로 반영됩니다.
- 합침 상태는 카드별로 저장되고, 「합침 해제」로 되돌릴 수 있습니다.
- API 요청 실패 시 연결 프로필 점검 안내를 함께 표시합니다.

## v1.1.2 템플릿 검증

- 설정 화면을 불러오지 못한 경우 알 수 없는 에러 대신 실제 경로가 포함된 명확한 안내를 표시합니다.

## v1.1.1 설치 경로 자동 감지

- 확장이 설치된 폴더 이름(=깃허브 저장소 이름)이 무엇이든 설정 화면을 올바르게 불러오도록 경로를 자동 감지합니다.
- 깃허브 저장소로 설치하는 경우 manifest.json이 저장소 루트에 있어야 합니다.

## v1.1.0 연결 분리와 UI 개편

- 별도 Connection Profile을 고르면 메인 API 연결과 완전히 분리된 백그라운드 경로로 프로필을 생성합니다. 채팅 생성 중에도 겹치지 않습니다.
- 「현재 연결 사용」인 경우, 메인 연결이 채팅을 생성하는 중이면 요청을 큐에 넣고 생성이 끝난 뒤 자동으로 실행합니다.
- 설정을 별도 탭으로 분리하고(캐스팅 후보 / 설정), 모든 버튼을 가로 배치로 정리했습니다.
- 채팅 전환·확장 비활성화 시 대기 중인 요청과 진행 중인 API 호출을 정리합니다.

## 동작 방식

1. **후보 감지 (로컬, 무료)** — 최근 AI 답변을 스캔해서, 어떤 캐릭터 카드에도 없는 이름이 여러 답변에 반복 등장하면 캐스팅 후보로 올립니다. 한국어는 조사(가/는/를/에게…)가 붙은 형태로, 영어는 문장 중간에 등장하는 대문자 이름으로 판별합니다. 인포패널과 태그·HTML 블록 안의 텍스트는 스캔에서 제외합니다.
2. **프로필 생성 (버튼을 누를 때만 API 사용)** — 후보 옆의 「🎭 로어북 생성」을 누르면 그 NPC가 등장한 장면들을 AI에게 보내 외모·성격·말투·관계·알려진 사실을 정리합니다. 예시 대사는 AI가 지어내지 않고 실제 채팅 원문에서 발췌된 것만 저장합니다.
3. **로어북 저장** — 정리된 프로필을 카드 양식 텍스트로 만들어 로어북 항목으로 저장합니다. 키워드는 NPC 이름과 별칭이라, 그 이름이 채팅에 등장할 때만 컨텍스트에 주입되고 안 나올 땐 토큰을 쓰지 않습니다.

## 저장 위치

- **캐릭터 로어북 (기본값)** — 같은 카드로 새 챗을 파도 NPC가 따라옵니다. 카드에 이미 연결된 로어북이 있으면 그 로어북에 항목을 추가하고, 없으면 `캐스팅룸-캐릭터이름` 로어북을 만들어 카드에 자동 연결합니다.
- **채팅 로어북** — 이 채팅 안에서만 NPC가 유지됩니다. 설정에서 바꿀 수 있습니다.
- **그룹챗** — 어느 카드에 묶을지 정할 수 없으므로 항상 채팅 로어북에 저장합니다.

## 주요 기능

- 카드에 없는 이름의 반복 등장 감지 (한국어 조사 처리, 영어 대문자 이름 처리)
- 후보별 등장 장면 근거 보기
- 카드 양식(외모/성격/말투/관계/사실/예시 대사) 로어북 항목 생성
- 이미 데뷔한 NPC의 「갱신」 — 기존 프로필과 새 등장 장면을 합쳐 다시 정리
- 후보 「무시」 — 카드별로 저장되어 다시 올라오지 않음
- AI 응답 새니타이징 — 태그·역할 접두어 제거, 프롬프트 탈취 지시 거부, 지어낸 예시 대사 필터링
- 저장 전 확인 팝업으로 내용 미리보기

## 설치

- **깃허브 설치**: 저장소 URL을 SillyTavern의 `확장 → 확장 설치`에 입력합니다. manifest.json과 index.js가 저장소 **루트**에 있어야 합니다(폴더로 감싸서 올리면 설치에 실패합니다).
- **수동 설치**: 이 폴더를 `data/default-user/extensions/` 아래에 놓고 SillyTavern을 새로고침합니다. 폴더 이름은 자유입니다.

## 데이터와 안전

- API 키를 저장하지 않습니다. 프로필 생성은 SillyTavern의 현재 연결 또는 선택한 Connection Profile을 사용합니다.
- API 호출은 「로어북 생성」·「갱신」 버튼을 누를 때만 발생합니다. 자동 호출은 없습니다.
- 이름 감지는 브라우저 안에서만 처리됩니다.
- 로어북 항목 외에는 캐릭터 카드를 수정하지 않습니다. 카드에 연결된 로어북이 없을 때 새 로어북 이름을 카드의 로어북 연결(`data.extensions.world`)에 기록하는 것이 유일한 카드 변경입니다.

## 알아둘 점

- 이름 감지는 휴리스틱이라 오탐이 있습니다(지명이나 반복되는 사물이 후보로 올라올 수 있음). 후보는 자동으로 로어북이 되지 않고, 항상 사용자가 골라서 생성합니다.
- 로어북 저장은 SillyTavern이 확장에 제공하는 API를 사용하며, 버전에 따라 제공 여부가 다를 수 있습니다. API를 찾지 못하면 저장하지 않고 안내 메시지를 표시합니다. 카드 자동 연결에 실패한 경우에는 캐릭터 패널의 🌐 버튼에서 직접 선택하면 됩니다.
- 생성된 항목은 일반 로어북 항목이므로 월드인포 편집기에서 자유롭게 수정할 수 있습니다.
