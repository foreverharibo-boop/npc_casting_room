내부 스캔 결과
생성된 초안 

          

            
            
            
          

        


        

          
          
          
          선택 무시는 체크한 후보를 한 번에 목록에서 지워요. 같은 NPC의 성·이름·별명만 선택 합치기로 묶어 주세요.
        

        

        

          🎬
          아직 캐스팅 후보가 없어요
        


        

          

            데뷔한 NPC
            캐스팅룸이 만든 로어북 항목이에요. 삭제된 항목은 현재 채팅에서 새로 만들 수 있어요. 이전 본문은 복구되지 않아요.
          

          
        

        

        

          아직 데뷔한 NPC가 없어요
        

      


      

        
        

        
        5 이상 원하는 개수를 직접 입력해요. 이름 감지와 「로어북 생성」 시 AI에게 보낼 장면 수집이 모두 이 범위를 봐요.

        

        

        
        기본형이 가장 짧은 5줄 요약이에요. 중간형은 캐릭터 시트에서 관계·성격·말투·배경 등을 추려 쓰고, 캐릭터 시트 따라하기는 현재 카드의 항목 구조를 그대로 따릅니다.

        

          
          항목 이름·순서·길이·표기법을 자유롭게 적어 주세요. 입력하는 동안 자동 저장돼요. NPC 이름과 별명은 로어북 키워드로 별도 저장되며, 출력 언어와 추론 설정은 아래 옵션을 따라요.
        


        
        로어북 항목의 내용을 항상 이 언어로 작성해요. 시트의 항목 라벨·마크업은 견본 그대로 두고, "(추정)" 표시와 예시 대사(원문 발췌)는 언어 설정과 무관하게 유지돼요.

        
        장면에 직접 나오지 않은 항목도 NPC의 행동·말투에서 그럴듯하게 추론해 채워요. 추론한 값에는 "(추정)"이 붙어서 관찰된 사실과 구분돼요. 끄면 확인된 정보만 기록해요.

        
        256 이상 원하는 값을 직접 입력해요. 상한은 없어요 — 캐릭터 시트가 길면 넉넉하게 잡아 주세요. 추론(thinking) 모델은 생각에 토큰을 쓰기 때문에 응답이 비거나 잘리면 이 값을 더 올리면 돼요.
        별도 Connection Profile을 고르면 메인 연결과 완전히 분리된 백그라운드 경로로 요청해서, 채팅 생성 중에도 겹치지 않아요. 「현재 연결 사용」인 경우에는 채팅 생성이 끝날 때까지 기다렸다가 자동으로 실행해요.

        

          
        


        설정은 변경 즉시 저장돼요. 「다시 스캔」은 API를 사용하지 않고, 「AI 스캔」·「로어북 생성」·「갱신」은 선택한 연결을 사용해요.
