NPC 캐스팅룸 새 NPC를 기다리는 중이에요
캐스팅 후보 카드에 없는 이름이 반복 등장하면 여기에 올라와요
같은 NPC가 성·이름·별명으로 따로 잡혔다면 체크한 뒤 합쳐 주세요. 합친 이름 전부가 로어북 키워드가 돼요.
🎬 아직 캐스팅 후보가 없어요
데뷔한 NPC 캐스팅룸이 만든 로어북 항목이에요. 갱신하면 새 등장 장면까지 반영해요.
아직 데뷔한 NPC가 없어요
시트 양식을 따라하면 현재 카드 설명의 구조(항목 이름·순서·마크업)를 그대로 흉내 내서 NPC 항목을 작성해요. 카드 설명이 비어 있거나 그룹챗이면 기본 양식으로 저장돼요. 장면에 직접 나오지 않은 항목도 NPC의 행동·말투에서 그럴듯하게 추론해 채워요. 추론한 값에는 "(추정)"이 붙어서 관찰된 사실과 구분돼요. 끄면 확인된 정보만 기록해요. 256~30000 사이에서 원하는 값을 직접 입력해요. 추론(thinking) 모델은 생각에 토큰을 쓰기 때문에 응답이 비거나 잘리면 이 값을 올려 주세요 (권장 3000 이상). 별도 Connection Profile을 고르면 메인 연결과 완전히 분리된 백그라운드 경로로 요청해서, 채팅 생성 중에도 겹치지 않아요. 「현재 연결 사용」인 경우에는 채팅 생성이 끝날 때까지 기다렸다가 자동으로 실행해요.
설정은 변경 즉시 저장돼요. 이름 감지는 브라우저 안에서만 처리되고, API는 「로어북 생성」·「갱신」을 누를 때만 사용해요.
